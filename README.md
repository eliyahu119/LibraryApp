# Library Application

This is a simple library management application built with Windows Forms.

## Features

*   Add, edit, and search for books.
*   Add, edit, and search for members.
*   Create and manage loans.
*   Return books.

## Setup

1.  Clone the repository.
2.  Open the `libaryApp.sln` file in Visual Studio.
3.  Build the solution.
4.  Run the application.

## Database

The application uses a local SQL Server database (`.mdf` file). The database file is included in the project. The connection string is configured in the `DataManager.cs` file.
